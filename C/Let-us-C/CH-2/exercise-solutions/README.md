# Chapter 2 – Let Us C

## Exercise Problems

### (a)

If a five-digit number is input through the keyboard, write a program to calculate the sum of its digits. (Hint: Use the modulus operator %)

**Concepts Practiced**
- Modulus operator (`%`)
- Integer division
- Arithmetic operations

---

### (b)

Write a program to receive Cartesian co-ordinates (x, y) of a point and convert them into polar co-ordinates (r, o).

Hint: r = sqrt(x ^ 2 + y ^ 2) and varphi = arctan(y / x)

**Concepts Practiced**
- Mathematical formulas
- Square root
- Trigonometric functions
- Coordinate systems

---

### (c)

Write a program to receive values of latitude (L1, L2) and longitude (G1, G2), in degrees, of two places on the earth and output the distance (D) between them in nautical miles.

The formula for distance in nautical miles is:

D =3963 cos^ -1 (sin L1 sin L2 + cos L1 cos L2 cos (G2-G1))

**Concepts Practiced**
- Trigonometric functions
- Mathematical formulas
- Floating-point arithmetic

---

### (d)

Wind-chill factor is the felt air temperature on exposed skin due to wind. The wind-chill temperature is always lower than the air temperature, and is calculated as per the following formula:

wcf=35.74+0.6215t+ (0.4275t-35.75) v0.16

where t is temperature and v is wind velocity. Write a program to receive values of t and v and calculate wind-chill factor (wcf).

**Concepts Practiced**
- Mathematical expressions
- Floating-point arithmetic
- Exponents

---

### (e)

If value of an angle is input through the keyboard, write a program to print all its Trigonometric ratios.

**Concepts Practiced**
- Trigonometric functions
- Math library
- Angle calculations

---

### (f)

Two numbers are input through the keyboard into two locations C and D. Write a program to interchange the contents of C and D.

**Concepts Practiced**
- Variables
- Assignment operations
- Swapping values
