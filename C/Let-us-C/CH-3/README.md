# Chapter 3 – Decision Control Instruction

This directory contains my solutions to the "selected programming exercises" from **Chapter 3** of *Let Us C* by Yashavant Kanetkar.

---

## Problems

### (b)

If ages of Ram, Shyam and Ajay are input through the keyboard write a program to determine the youngest of the three.

**Learning Outcomes**

- statements (`if` `else if` `else`)

- Relational operators
- Logical operators
- Comparing multiple values
---

### (d)

Write a program to find the value of a number entered through the keyboard.

**Learning Outcomes**

- statements (`if-else`)
- Relational operators
- Arithmetic operations
- Handling positive and negative numbers

---

### (f)

Given three points **(x1 y1) (x2, y2)** and **(y3)** write a program to check if the three points fall on one straight line.

**Learning Outcomes**

- Conditional statements
- Coordinate geometry
- Equality comparison
---

### (g)

Given the coordinates **(x, y)** of center of a circle and its radius write a program that will determine whether a point lies inside the circle on the circle or outside the circle. *(Hint: Use `sqrt()` and `pow()` functions)*

**Learning Outcomes**

- Mathematical functions (`sqrt()` `pow()`)
- Distance calculation
- Coordinate geometry

---

### (i)

According to calendar it was Monday on the date 01/01/01. If any year is input through the keyboard write a program to find out what is the day, on January of this year.

**Learning Outcomes**

- Arithmetic operations
- Leap year concepts
- Modular
- Problem-solving and logical reasoning
